# Akshat Fertilizer — B2B ERP & Distribution Portal

This repository ships a single bootstrap script, `setup.sh`, that generates the full Next.js 14 + Supabase application.

```bash
chmod +x setup.sh
./setup.sh akshat-b2b      # needs Node.js >= 18.17, npm, git
```

The generated project contains its own README with Supabase setup, the API reference, the Tally connector loop and
the Vercel + cPanel (`b2b.` CNAME) deployment steps.
